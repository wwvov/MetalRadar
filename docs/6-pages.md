# 页面规格 (精简版)

## 1. 首页 - 新闻资讯
- 左侧导航，手动刷新按钮。
- 四个 Tab：全部/关注公司/敏感品种/宏观政策。"关注公司""敏感品种"有筛选器，下拉多选内容来自用户关注的公司和它们的敏感品种列表，动态生成。
- 新闻卡片 (NewsCard)：关联度色条、标题、摘要、来源、时间、实体标签、收藏星标、展开按钮。所有数据由 API 动态提供。
- 关联度计算：同时匹配公司+金属红→置顶；仅公司蓝；仅金属黄；无关灰。宏观Tab全部灰色。关联度由前端根据用户关注列表和新闻的 company_entities / metal_entities 实时计算。
- 收藏时弹出关联公司浮窗，可选公司列表来自用户已关注的公司。
- 无关注公司时显示引导卡片。
- 数据：使用 `useNews` hook 调用 `GET /news`。
以下是对当前新闻资讯页布局设计的详细描述，按从上到下、从左到右的视觉层次逐一说明。

### 4. 新闻卡片（核心交互单元）

每条新闻统一采用卡片组件，通过左侧色条区分关联度等级：

```
┌─│──────────────────────────────────────────────────────────┐
│ │  新闻标题（加粗，最多2行）                    07/03 14:30 │
│ │                                                          │
│ │  摘要：前80字自动截取...                        来源:东财 │
│ │                                                          │
│ │  🏷 [赛力斯] [锂] [铜价] [供应中断]                      │
│ │                                                          │
│ │  ☆收藏    ✓设为已读    ▼展开              最高相关       │
└─│──────────────────────────────────────────────────────────┘
   ↑
   左侧1px色条：
   红色 = 最高相关(同时匹配公司+金属，卡片加阴影)
   绿色 = 高相关(匹配关注公司)
   黄色 = 中相关(匹配敏感品种)
   灰色 = 低相关(未匹配)
```

**卡片结构**（`bg-card border border-border rounded-lg`）：
- **左侧关联度色条**：`absolute left-0 w-1`，4 级颜色
- **标题行**：
  - 标题（`text-[15px] font-semibold line-clamp-2`），hover 变绿色
  - 未读新闻标题后有绿色小圆点（`size-1.5 bg-emerald-500`）
  - 右侧时间戳（`text-[12px] tabular-nums`，格式"MM/DD HH:MM"）
- **摘要行**：
  - 摘要文本（`text-[13px] line-clamp-2`，最多 2 行）
  - 右侧来源标签（`bg-muted px-1.5 py-0.5 rounded`，绿色圆点 + "来源:东财"）
- **实体标签行**（`flex flex-wrap gap-1.5`）：
  - Tag 图标 + 标签列表（最多 6 个）
  - 公司标签：绿色背景（`bg-emerald-50 text-emerald-700`）
  - 金属标签：琥珀色背景（`bg-amber-50 text-amber-700`）
  - 事件标签：红色背景（`bg-rose-50 text-rose-700`）
  - 点击标签可触发按该标签过滤
  - 宏观政策 Tab 下仅显示事件类标签（隐藏公司/金属标签）
- **底部操作栏**（`border-t border-border/60 pt-2`）：
  - 左侧三个操作按钮：
    - 收藏（空心星 → 点击变实心星"已收藏" + 可关联公司）
    - 设为已读（Check 图标，已读后变灰 disabled）
    - 展开（ChevronDown 图标，点击旋转 180°）
  - 右侧关联度文字标识（Sparkles 图标 + "最高相关"/"高相关"等，颜色对应色条）

**展开详情面板**（`border-t bg-muted/30`）：
- 点击卡片或"展开"按钮，在卡片下方滑出
- 显示新闻全文（`text-[13px] leading-relaxed whitespace-pre-line`）

## 三、交互逻辑总结

| 交互 | 行为 |
|------|------|
| 点击 Tab | 即时过滤列表，无需重新加载；切换时清除标签筛选 |
| 点击公司筛选条 | 只显示该公司关联的新闻；再点一次取消 |
| 点击品种筛选条 | 只显示该品种关联的新闻；再点一次取消 |
| 点击新闻卡片 | 展开/收起详情面板，同时标记为已读 |
| 点击实体标签 | 按该标签过滤列表；再点一次清除 |
| 点击收藏 | 切换收藏状态（空心星↔实心星） |
| 点击"全部已读" | 当前 Tab 下所有新闻标记为已读 |
| 点击"刷新资讯" | 5 秒防抖；刷新中显示 spinner；刷新后更新时间 |
| 宏观快讯悬停 | 暂停滚动动画 |
| 已读新闻 | 卡片整体透明度降至 75% |

## 四、响应式设计

| 断点 | 变化 |
|------|------|
| `< md` (移动端) | 侧边栏隐藏（汉堡菜单触发抽屉）；Header 副标题隐藏；关注公司摘要隐藏；预警只显示数字 |
| `md` ~ `lg` | 侧边栏显示；Header 副标题显示；预警文字显示 |
| `≥ lg` | 关注公司摘要显示 |
| `≥ xl` | 无额外变化 |

Tab 栏在小屏可横向滚动（`overflow-x-auto custom-scroll`），筛选条同样可横向滚动。

## 2. 我的关注
- 上方：关注公司卡片列表（横向），点击选中。列表数据来自 `GET /user/follows`。
- 下方：选中公司的完整画像面板（基础信息、产业链位置、敏感品种表格、财报摘要），可编辑保存。画像数据来自 `GET /companies/{id}`。
- 新增关注抽屉：搜索公司 → 上传财报(可选) → AI生成画像 → 确认修正。搜索结果显示由 `GET /companies/search` 动态返回。
- 新闻收藏子模块：过滤查看已收藏新闻，支持取消。数据来自 `GET /news?tab=favorites`。

页面分为上下两个区域：上方是已关注公司卡片列表，下方是选中公司的完整画像详情。点击“新增关注”时，弹出创建向导。

1. 已关注公司列表
功能：展示用户所有已关注的公司，支持快速切换查看。
每个公司卡片展示精简信息：
公司名称 + 股票代码
所属行业
产业链位置标签（如“下游·整车制造”）
主要敏感品种（最多展示3个，超出折叠）
画像数据更新时间

交互：
点击卡片 → 下方详情面板切换为该公司的完整画像。
悬停卡片 → 显示“编辑”和“删除”按钮。
无关注公司时 → 显示空状态引导：“你还没有关注任何公司，点击新增关注开始分析。”


2. 公司画像详情面板
选中某家公司后，下方展示其完整的结构化画像，所有字段均可查看和编辑。
面板结构
区域一：基础信息（只读）
来源于数据接口自动拉取，不可编辑：
公司全称、简称、股票代码
所属行业
主营业务描述

区域二：产业链位置（可编辑）
来源于大模型判断，用户可修正：
产业链层级：上游 / 中游 / 下游
行业细分环节：如“汽车整车制造”
简要说明：如“终端产品制造商，采购中游零部件和电池”

提供一个“修改”按钮，点击后下拉选择产业链层级和细分环节（提供预设分类选项，也支持自定义输入）。

区域三：敏感原材料品种列表（可编辑，核心组件）
来源于大模型判断，以表格形式展示，每行一个品种：
每行的“成本占比估算”和“影响方向”可直接在表格内编辑。
“数据来源”列以标签形式展示（“财报披露”为绿色，“行业推断”为黄色），提醒用户该数据的可靠程度。
表格下方提供“添加品种”按钮，用户可手动补充大模型遗漏的品种。

区域四：财报基准数据（只读）
若用户上传了财报，展示提取到的关键数据摘要：
营业成本构成（直接材料%、直接人工%、制造费用%）
近几期毛利率
存货周转天数
数据对应报告期

操作栏：
[保存修改]：将用户手动修正后的画像标签更新到数据库。
[重新生成]：若用户更换了新的财报，可重新上传并触发大模型重新生成画像。
[删除关注]：从关注列表中移除该公司，同时删除其所有关联数据（收藏新闻的关联关系保留但解除绑定）。

3. 新增关注向导（弹窗/侧边抽屉）
点击“新增关注”按钮后，以抽屉面板从右侧滑出，包含以下步骤：
步骤一：定位公司
输入框：输入公司代码或公司名称进行搜索。
搜索结果列表：显示匹配公司，点击选中。
系统自动调用数据接口拉取公司基础信息并展示确认。
用户确认后进入下一步。

步骤二：上传财报（可选）
上传区域：拖拽或点击上传PDF文件。
上传后显示文件名和大小。
“跳过”按钮：不上传财报，后续画像基于行业推断。
若上传，系统自动抽取营业成本附注等关键段落（后台处理，前端显示“正在解析财报…”加载状态）。

步骤三：生成画像
点击“开始生成画像”。
前端显示处理进度（如“正在分析主营业务…”“正在提取原材料依赖…”）。
大模型处理完成后，跳转到画像详情面板。
画像中所有字段已自动填充。

步骤四：确认与修正（即步骤二后的画像详情面板）
用户检查产业链位置、敏感品种、成本占比等是否正确。
标记为“行业推断”的品种尤其需要用户确认或补充。
修改完成后点击“保存”，画像持久化入库。



4. 新闻收藏子模块
页面底部或通过Tab切换，可查看用户从首页收藏的所有新闻：
列表展示已收藏新闻卡片（与首页样式一致）。
支持按关联公司、品种、收藏时间筛选。
每条新闻显示其关联的公司标签。
支持取消收藏。






## 3. 公司详情
- 头部信息栏：公司名称、产业链标签（可跳转Agent）、品种标签（跳转分区三），下拉切换公司。所有标签文本来自画像数据。
- 分区一：左K线图（带MA、成交量），右敏感品种小图（带切换），下背离分析卡片。K线数据来自 `/stocks/{code}/kline`，小图数据来自 `/futures/{contract}/kline`，背离卡片数据来自 `/companies/{id}/divergence`。
- 分区二：左财务指标卡（可展开季度图）+ 材料成本压力仪表（绿黄红条），右成本结构桑基图。压力仪表数据来自 `/companies/{id}/cost-pressure`，桑基图数据根据财报动态构造。
- 分区三：品种切换Tab → 实时行情卡 + 历史波动率锥 + 价格分位温度计。行情来自 `/futures/{contract}/quote`，波动率锥来自 `/futures/{contract}/volatility-cone`，分位来自 `/futures/{contract}/price-percentile`。

## 4. AI Agent 交互页
- 公司选择器 + 三个场景按钮（风险趋势扫描、事件传导推演、自定义提问）。
- 对话区域：气泡展示，Agent回复可附带 `chart` 对象，由 ChartRenderer 渲染 ECharts。chart 数据完全由 Agent 输出。
- 数据：`useAgent` hook 调用 `POST /chat`，传入公司id和消息。
