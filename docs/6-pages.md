### 1.1 左侧导航 (Layout)

- **Logo**: MetalRadar 雷达图标 + 品牌名，绿色主题 (`bg-green-800`)
- **导航项**: 新闻资讯 / 我的关注 / 公司详情 / AI Agent
- **激活态**: `bg-green-800 text-white` + 阴影
- **默认态**: `text-slate-600`，hover 变 `bg-green-50 text-green-800`
- **底部**: 版本号 `v0.1.0`
- **全局关注加载**: `useFollows()` 在 Layout 层调用，确保所有页面实时同步关注列表；关注变更时自动 invalidate `['news']` 查询缓存

### 1.2 顶部 Header (sticky)

```
┌──────────────────────────────────────────────────────────────┐
│ 新闻资讯 [实时]  多源融合·智能识别·关联预警     [刷新状态] [刷新数据]  关注公司 N  │ ⚠ N条预警 │
└──────────────────────────────────────────────────────────────┘
```

- **标题**: "新闻资讯" (`text-[17px] font-semibold`)
- **实时徽章**: `bg-emerald-100 text-emerald-700`，`text-[10px]`
- **副标题**: "多源融合 · 智能识别 · 关联预警"（`hidden sm:block`）
- **新闻刷新状态**: 刷新中显示蓝色 spinner + 进度文字（如"正在从 akshare 获取新闻…"）
- **刷新按钮**: "刷新数据" + RefreshCw 图标，调用 `POST /api/news/refresh` 后台管道（抓取 → 入库 → LLM 分类），前端 2s 轮询 `/api/news/refresh/status` 直到完成
- **关注公司摘要**: Sparkles 图标 + "关注公司 N"（`hidden lg:flex`）
- **风险预警**: `bg-rose-50 text-rose-700`，显示红色高关联未读条数（alertCount，仅 >0 显示）

### 1.3 宏观快讯滚动条 (MacroTicker)

```
┌────────┬─────────────────────────────────────┬──────────┐
│ 🔴LIVE │  碳酸锂期货大涨5% · 宁德时代发布     │ 刷新资讯  │

```

- **数据源**: `GET /api/news?tab=macro_panel` — 纯宏观/政策类新闻（无公司实体 + 无金属实体），最多 15 条
- **顶部彩条**: 1px 三色渐变 `from-emerald-400 via-amber-400 to-rose-400`
- **深色背景**: `from-slate-900 to-slate-800`，白色文字
- **左侧 LIVE 区**: 脉动红点 (`animate-ping`)、Radio 图标、"宏观快讯" 标签
- **中部滚动**: CSS marquee 动画 60s 一轮，hover 暂停，左右渐隐遮罩
- **右侧刷新区**: 最后刷新时间、"刷新资讯"按钮（5s 防抖）、刷新中显示 spinner

### 1.4 新闻不足提示横幅

- **触发条件**: 总新闻数 (mainQuery + macroQuery) < 20 条，且非加载中，且未在刷新中
- **样式**: `bg-amber-50 border-amber-200`，琥珀色警告
- **内容**: "当前仅有 N 条新闻，点击「刷新数据」从东方财富、上海金属网、新浪财经获取最新资讯"
- **操作**: "立即刷新"按钮，触发 `newsRefresh.startRefresh()`

### 1.5 上海金属网专属区块 (ShmetBlock)

独立卡片区块，展示上海金属网产业快讯，位于宏观快讯下方、Tab 列表上方：

- **标题**: "上海金属网 · 产业快讯" + Factory 图标
- **15 个品类 Tab**: 要闻 / 铜 / 铝 / 铅 / 锌 / 镍 / 锡 / 贵金属 / 小金属 / 铁矿石 / 螺纹钢 / 热卷 / 不锈钢 / 原油 / 纯碱
  - 品类 Tab（如"贵金属""小金属"）发送 `metal_category` 参数，后端按 METAL_CATEGORY_MAP 展开子品种匹配
  - 单品种 Tab（如"铜"）发送 `metal` 参数精确匹配
  - "要闻"不传参数，返回全部上海金属网新闻
- **数据源**: `GET /api/news?tab=shmet_block`，不走主聚合流
- **样式**: 绿色系卡片 (`border-green-200`)，`max-h-[500px]` 滚动区
- **后端逻辑**: 仅筛选 `source == "上海金属网"`，品类/品种可选过滤

### 1.7 无关注公司引导 (EmptyGuide)

- **触发条件**: `follows.length === 0`
- 引导用户去「我的关注」页面添加公司

### 1.8 Tab 栏 + 筛选芯片

**Tab 栏**（sticky，`border-b`）：
- 4 个 Tab: 全部 / 关注公司 / 敏感品种 / 宏观政策
- 每个 Tab 右侧未读红点:
  - 激活态: `bg-emerald-600 text-white`
  - 非激活态: `bg-rose-500 text-white`
  - 数字 >99 显示 "99+"
- 未读计数按 Tab 维度统计:
  - `all`: 全部未读数
  - `followed_companies`: 含关注公司实体的未读新闻
  - `sensitive_metals`: 含金属实体的未读新闻
  - `macro`: 灰级关联 (relevance_level=gray) 的未读新闻
- 右侧: 总数 + "全部已读"按钮

**后端 Tab 路由**:
- `all`: 全量新闻，排除上海金属网来源（走专属区块展示）
- `followed_companies`: 聚合所有来源（含上海金属网），按关注公司 `company_entities` 过滤
- `sensitive_metals`: 聚合所有来源（含上海金属网），从 `company_materials` 提取关注公司的品种 → 按 `metal_entities` 过滤 + `is_relevant=True` + `json_array_length(metal_entities) > 0`
- `macro`: 排除上海金属网，仅灰级关联 (`relevance_level == "gray"`)
- `macro_panel`: 纯宏观（无公司 + 无金属实体），用于滚动条
- `shmet_block`: 仅上海金属网来源，用于专属区块

**筛选芯片**:

关注公司 Tab — 绿色筛选条:
- Building2 图标 + "按公司筛选"
- "全部 (N)" + 各公司芯片 (如"赛力斯 (2)")
- 芯片数据来源: `follows` 列表（所有关注公司均显示，即使 count=0，与品种筛选行为一致）
- 计数来源: 当前新闻列表中匹配 `company_entities` 的数量
- 激活态: `bg-emerald-600 text-white`，非激活: `bg-emerald-50 text-emerald-700`
- 点击芯片 → `companyFilter` → 前端过滤 `n.company_entities.includes(companyFilter)`

敏感品种 Tab — 琥珀色筛选条:
- Boxes 图标 + "按品种筛选"
- "全部 (N)" + 各品种芯片 (如"锂 (4)")
- 芯片数据来源: 从所有关注公司的 `portrait.materials` 提取品种名 → 统计在当前新闻中的出现次数 → 按次数倒序
- 无新闻的品种也保留 (count=0)，保持可见性
- 激活态: `bg-amber-600 text-white`，非激活: `bg-amber-50 text-amber-700`
- 点击芯片 → `metalFilter` → 前端过滤 `n.metal_entities.includes(metalFilter)`

```

│ │ ● 新闻标题（加粗，最多2行）            MM/DD HH:MM │

```

- **左侧关联度色条**: `border-l-[3px]`
  - `red`: `border-l-rose-500` + `shadow-md shadow-rose-50` — 最高相关（同时匹配公司+金属）
  - `blue`: `border-l-emerald-500` — 高相关（匹配关注公司）
  - `yellow`: `border-l-amber-500` — 中相关（匹配敏感品种）
  - `gray`: `border-l-gray-300` — 低相关
- **已读态**: `opacity-75`
- **未读标记**: 标题前绿色圆点 (`size-1.5 bg-emerald-500`)
- **标题**: `text-[15px] font-semibold line-clamp-2`，hover `text-emerald-700`
- **摘要**: 前 80 字 + "…"，右侧来源标签
- **标签行**: 公司标签 (`bg-emerald-50`)、金属标签 (`bg-amber-50`)、事件标签 (`bg-rose-50`)、情绪标签（利好/利空/中性）
- **宏观模式**: 隐藏公司/金属标签，仅显示事件标签
- **操作栏**:
  - 收藏 (Star): 未收藏点击弹出 FavoritePopover 选择关联公司；已收藏点击取消
  - 设为已读 (Check): 已读后 disabled
  - 展开/收起 (ChevronDown): 点击展开详情面板（含全文 + 关联公司建议）
- **点击卡片**: 展开并自动标记已读（首次）
- **点击标签**: 触发对应的 tag 过滤（company/metal/event）
- **关联度计算** (`_calc_relevance`): 前端根据用户关注列表与新闻 `company_entities`/`metal_entities` 实时计算 — 同时匹配→red，仅公司→blue，仅金属→yellow，无关→gray
- **收藏关联**: FavoritePopover 推荐当前新闻中出现的关注公司，用户选择关联或直接收藏

### 2.1 关注公司卡片列表

- **数据来源**: `useWatchlist()` → `follows` 列表 + `useCompanyDetails(followsIds)` 批量获取画像
- **横向滚动**: `ScrollArea` + `flex gap-3`
- **每张卡片 (CompanyCard) 展示**:
  - 公司名称 + 股票代码
  - 产业链位置标签（如"下游·整车制造"，来自 `portrait.position`）
  - 敏感品种折叠列表（来自 `portrait.materials`，最多展开显示 3 个）
  - 画像更新时间
- **交互**:
  - 点击卡片 → 下方切换为该公司的完整画像
  - 悬停显示编辑/删除按钮
  - 无关注公司 → 空状态引导卡片
- **画像批量加载**: `useCompanyDetails` 调用 `useQueries` 并行请求所有关注公司的 `GET /companies/{id}`，触发后端三层自动修复（记录不存在→创建、画像无效→重新生成、失败→返回占位）

### 2.2 公司画像详情面板 (CompanyPortrait)

选中公司后展示，`PortraitLoader` 按需加载单个公司完整画像。四个区域：

- **区域一 — 基础信息**（只读）: 公司全称、股票代码、所属行业、主营业务描述
- **区域二 — 产业链位置**（可编辑）: 产业链层级（上游/中游/下游）、行业细分环节、简要说明。提供下拉选择 + 自定义输入
- **区域三 — 敏感原材料品种列表**（可编辑表格）: 品种名称、成本占比估算、影响方向、数据来源标签（"财报披露"绿色/"行业推断"黄色）。支持行内编辑、添加品种、删除品种
- **区域四 — 财报基准数据**（只读）: 营业成本构成、毛利率、存货周转天数、报告期

**操作栏**: [保存修改] `PUT /companies/{id}/portrait` | [重新生成] 上传新财报触发 `POST /companies/{id}/regenerate` | [删除关注]

### 2.3 新增关注向导 (AddCompanyDrawer)

右侧滑出抽屉，四步骤：

- **Step 1 — 搜索公司**: 输入框防抖搜索 A 股上市公司（`GET /api/companies/search`，底层 akshare），点击选中
- **Step 2 — 上传财报**（可选）: PDF 拖拽上传，AI 自动提取营业成本附注。"跳过"按钮跳过
- **Step 3 — AI 生成画像**: 调用 `POST /api/companies/init`，传入财报文本 + 公司信息，LLM 分析生成产业链画像
- **Step 4 — 确认修正**: 展示 AI 生成的画像，用户检查修正后保存。所有字段自动填充，标记为"行业推断"的品种需用户确认

**画像生成** (后端 `llm_service.py`):
- DeepSeek/OpenAI 大模型，System Prompt 覆盖锂电池/汽车/有色/钢铁/消费电子五大行业
- `response_format=json_object` 强制 JSON 输出
- 3 次重试 + 指数退避 (2s/4s)
- 三级缓存: 内存 → 文件 (24h TTL) → akshare
- 画像质量校验: `industry` + `materials` 不能同时为空

**三层自动修复** (后端 `company_service.py`):
- 页面加载 → `GET /companies/{id}`:
  1. 记录不存在 → 自动创建 + LLM 生成 (fast: 15s/1retry)
  2. `portrait_generated=False` → 自动重新生成
  3. 画像有效 → 直接返回 (0.01s)

## 5. 新闻数据管道

### 多源抓取 (news_fetcher.py)

- **数据源**: akshare — 上海金属网 / 东方财富全球快讯 / 新浪财经全球快讯（3源）
- **文件缓存**: `.cache/news_raw.json`，TTL 5 分钟
- **反爬**: 5 秒冷却间隔（`SCRAPE_COOLDOWN = 5`）
- **去重**: MD5 哈希增量入库
- **API**: `POST /api/news/fetch` (force 参数强制刷新)

### LLM 智能分类 (news_classifier.py)

- **模型**: DeepSeek，批量处理 15 条/批
- **识别维度**: 34 种金属品种、10 种事件类型、情绪判断（利多/利空/中性）
- **关联度**: 红/蓝/黄/灰四级
- **公司实体格式**: 统一使用 6 位数字股票代码（如 "601899"），`followed_companies` 查询同时支持名称兜底匹配
- **一致性约束**: `metal_entities` + `company_entities` 双空时 → `is_relevant=false`, `relevance_level=gray`
- **API**: `POST /api/news/classify` (limit 参数控制处理条数)

### 完整刷新管道

- **API**: `POST /api/news/refresh` — 后台异步执行: 抓取 → 入库 → LLM 分类
- **状态查询**: `GET /api/news/refresh/status`
- **前端**: `useNewsRefresh` hook，2s 轮询进度，完成自动 refetch 新闻列表

### 新闻数据库

- **种子数据**: `POST /api/seed/sprint1` — 3家预配置公司 + 30+条覆盖新闻
- **akshare 源**: 实时抓取补充
- **SQLite**: WAL 模式 + `busy_timeout=5000` 防并发锁库
