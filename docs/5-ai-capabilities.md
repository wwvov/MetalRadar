# AI 能力与工作流

## 数据动态性声明
本章中出现的所有 Prompt 输出示例，仅用于说明大模型应返回的 JSON **结构**和**字段**。实际返回内容完全取决于输入的新闻文本、公司信息或用户提问，不存在任何预设值。

---

## 新闻实体识别与过滤
每条新闻入库前调用大模型，使用以下 Prompt：
你是金融新闻实体识别AI。从给定新闻中提取：

1. A股上市公司简称或全称。

2. 金属品种（仅限白名单：铜/铝/铅/锌/镍/锡/黄金/白银/铂/钯/锂/钴/稀土/钨/钼/锑/锰/硅/铁矿石/螺纹钢/热卷/线材）。

强制排除：资金、金额、银行、金融、基金、佣金、罚金、薪金、税金、银保监会、金牌等非金属语境。

输出 JSON：{"companies":[],"metals":[],"is_relevant":bool}

该 Prompt 使 AI 对每条新闻输出动态结果。companies 和 metals 数组的内容取决于新闻实际提到的实体，is_relevant 由 AI 判断。

## 公司画像生成
用户提交股票代码+财报PDF → 抽取文本 → 调用大模型：
根据公司主营业务和财报附注，输出 JSON：
{ "position": "上游/中游/下游", "position_detail": "...", "materials": [{"name":"...","cost_pct":... ,"source":"财报披露/行业推断","direction":"不利/有利","contract":"..."}] }
仅使用给定信息，成本占比未知时标注"行业推断"。


每个公司的 position、materials 列表均由大模型根据其实际业务动态生成。

## Agent 工具函数（后端实现）
- `search_risk_news(company_id, days=30)` → 从数据库查询与该公司的材料相关的风险新闻，返回的新闻列表完全取决于数据库中的实际数据。
- `get_price_trend(material, period)` → 从行情接口获取价格数据并计算趋势、分位、波动率，结果随市场变化。
- `get_cost_exposure(company_id, material)` → 从 company_materials 表读取该公司的成本占比和影响方向，值来自画像数据。

## Agent 对话流程
用户提问 → Planner 选择工具 → 调用工具获取实时结构化数据 → LLM 推理生成自然语言回复 + 可选 chart 参数 → 前端渲染。

## 内嵌图表 schema (ChartParam)
| type | 说明 | 必须包含的参数（结构） |
|------|------|----------------------|
| line | 价格走势+新闻标注 | 品种名, 时间序列数据, newsMarkPoints (日期与标签列表) |
| bar | 多品种/公司影响对比 | 名称列表, 影响方向, 程度标签 |
| flow | 影响路径简图 | 节点与边数据 |
| gauge | 价格分位温度计 | 当前值, 最低, 最高, 分位 |

chart 对象中的具体数据（如价格数值、新闻标签文本）完全由 Agent 根据当前查询动态填充。
