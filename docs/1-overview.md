# MetalRadar - 项目概述

## 产品定位

面向中小企业和金融机构的 AI 原材料风险分析平台。
帮助企业理解大宗商品价格波动对成本与利润的影响，为金融机构提供穿透式企业风险画像。

## 核心痛点

- 原材料价格、财报、行业新闻分散，关联分析靠人工
- 财报滞后，无法反映实时成本压力
- 缺乏将商品行情翻译为企业影响的工具

## 目标用户

| 角色               | 核心需求             |
| ---------------- | ---------------- |
| 中小企业（制造/新能源/汽车等） | 监控原材料价格风险，辅助采购决策 |
| 银行/保理/融资租赁       | 评估贷款企业原材料风险，动态预警 |
| 投研分析师            | 扫描产业链敏感度，发现背离信号  |

## 产品架构

- 新闻资讯（首页）：多源聚合、LLM智能分类、多Tab筛选(全部/关注公司/敏感品种/宏观)、收藏/已读、上海金属网快讯、宏观跑马灯
- 我的关注：公司管理(搜索/添加/删除)、AI画像生成与手动编辑、新闻收藏关联
- 公司详情（Sprint 2 — 部分完成）：市值走势（K线、期货对比、背离分析）、财务数据（核心指标、财报上传、成本压力仪表）
- 敏感金属仪表盘：期货实时行情、成本压力仪表、价格分位热力图、迷你K线走势、跨公司视角
- AI Agent 对话（Sprint 3 — 待实现）：风险扫描、事件推演、自由问答，内嵌图表
