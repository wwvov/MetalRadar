# MetalRadar - 项目概述

## 产品定位

面向中小企业和金融机构的 AI 原材料风险分析平台。
帮助企业理解大宗商品价格波动对成本与利润的影响，为金融机构提供穿透式企业风险画像。

## 核心痛点

- 原材料价格、财报、行业新闻分散，关联分析靠人工
- 财报滞后，无法反映实时成本压力
- 缺乏将商品行情翻译为企业影响的工具

## 目标用户

| 角色               | 核心需求             |
| ---------------- | ---------------- |
| 中小企业（制造/新能源/汽车等） | 监控原材料价格风险，辅助采购决策 |
| 银行/保理/融资租赁       | 评估贷款企业原材料风险，动态预警 |
| 投研分析师            | 扫描产业链敏感度，发现背离信号  |

## 产品架构

- 新闻资讯（首页）：聚合、过滤、收藏、关联
- 我的关注：公司管理、AI画像生成、新闻收藏
- 公司详情：K线、财务指标、材料成本压力、期货深度数据
- AI Agent 对话：风险扫描、事件推演、自由问答，内嵌图表
