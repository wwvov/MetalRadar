# MetalRadar - 项目概述

## 产品定位

面向中小企业和金融机构的 AI 原材料风险分析平台。
帮助企业理解大宗商品价格波动对成本与利润的影响，为金融机构提供穿透式企业风险画像。

## 核心痛点

- 原材料价格、财报、行业新闻分散，关联分析靠人工
- 财报滞后，无法反映实时成本压力
- 缺乏将商品行情翻译为企业影响的工具

## 目标用户

| 角色               | 核心需求             |
| ---------------- | ---------------- |
| 中小企业（制造/新能源/汽车等） | 监控原材料价格风险，辅助采购决策 |
| 银行/保理/融资租赁       | 评估贷款企业原材料风险，动态预警 |
| 投研分析师            | 扫描产业链敏感度，发现背离信号  |

## 产品架构

- 新闻资讯（首页）：多源聚合、LLM智能分类、多Tab筛选(全部/关注公司/敏感品种/宏观)、收藏/已读、上海金属网快讯、宏观跑马灯、自适应反爬退避
- 我的关注：公司管理(搜索/添加/删除)、AI画像生成与手动编辑、产业链全景分析(Mermaid流程图)、收藏新闻关联
- 公司详情：市值走势（K线、期货对比、背离分析）、财务数据（核心指标三分类、季度趋势图、成本压力仪表）、YTD涨跌幅
- 敏感金属仪表盘：期货实时行情、成本压力仪表（加权压力计算）、价格分位温度计（过去365/730天）、迷你K线走势、跨公司视角、行情新鲜度指示器
- 知识图谱：多公司产业链关系网络可视化（ReactFlow + dagre 布局 + 新闻/原材料/企业三类节点联动 + 节点详情面板 + AI 分析入口）
- AI Agent 对话：三栏式智能对话（会话管理 + 模型切换 + MRI 风险报告生成/导出 + 金属聚焦报告 + 多公司/多金属仪表盘）
